# Мост «Солнышко» → Павел

Гостевая `locations/solnyshko-park.html` — реклама.
`locations/solnyshko-after-hours.html` — игра у ворот и внутри парка.

- Вход: день рождения + дата открытки (аниматор может проверить карман) или
  реплика волонтёра. Дальше роли не важны.
- Внутри: общий план, пустая карусель, стенд с сахарной ватой и Ирина.
- Ирина благодарит, даёт затравку на кабинку, система **анонсирует** новый ID
  и отправляет в `staff.html?personnel=pavel`. Сам номер в сцене парка **не
  показывается**.
- Служебный ID Павла: `0274-P`. Он живёт на кадровой карточке и в поле найма,
  как `0091-A` и `0391-L`. Запрос ID на карточке копирует номер. Ввод `0274-P`
  на «Работе» открывает кабинку.
- Волна 1 футажа: `assets/guest/locations/solnyshko/`. Первый заход на хаб
  играет `gate-open-enter` один раз, затем луп `park-wide-15s`.

Проверка: `node scripts/validate-irina-solnyshko.js`.
Каркас ночи и футаж: `docs/SOLNYSHKO_NIGHT_STORY_AND_FOOTAGE.md`.
